Seguridad

Construido para
equipos técnicos

✓

AES-256-GCM

El estándar usado por gobiernos y bancos. Encriptación simétrica con vector de inicialización único por entrada.

✓

PBKDF2 · 200,000 iteraciones

Derivación de clave con sal aleatoria. Hace que los ataques de fuerza bruta sean computacionalmente inviables.

✓

Zero Knowledge

El servidor solo recibe datos encriptados. Sin tu contraseña maestra, nadie puede descifrarlos — ni nosotros.

✓

JWT + bcrypt

Autenticación con tokens firmados y contraseñas del sistema hasheadas con bcrypt (12 rounds).

// Encriptación client-side
async function encrypt(plain, master) {
const salt = crypto.getRandomValues(
new Uint8Array(16));
const key = await deriveKey(
master, salt, 200000);
return AES_GCM_encrypt(plain, key);
}
